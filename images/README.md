# Images

Every image this repository uses, or may use, lives here. Reference images by their path under `images/`;
don't add images elsewhere in the repository.

```
images/
├── overview/        the project infographic at the top of the README (generated)
├── steps/           the README installation step cards (generated)
├── badges/          the README platform badges (generated)
├── ui/              our own line icons (24 × 24)
├── illustrations/   our own drawings
├── user-interface/  the bridge as shown in home automation and on its own web page
└── brands/          third-party logos (not covered by this project's license)
```

## `overview/` — project infographic (generated)

| File | What |
|---|---|
| `aquaclean-bridge-overview.svg` | The infographic (1660 × 980). Built from the icons, drawings and logos in this folder. |
| `aquaclean-bridge-overview.png` | The same at 3× (4980 × 2940), shown at the top of the README. A PNG is used there so the text renders identically everywhere, whatever fonts the viewer has. |

Both are generated by `tools/overview/generate.py` from `tools/overview/overview.yaml`; don't edit them by hand.
Models, the language count and the recommended board come from `support/matrix.yaml`, and a route is only
drawn if the matrix marks it validated or supported.

```
python3 tools/overview/generate.py            # SVG, PNG (needs rsvg-convert) and the README snippet
python3 tools/overview/generate.py --check    # CI: fails if the SVG or README is out of date
```

The PNG is rendered against the Inter fonts bundled in `tools/overview/fonts/` only, so it looks the same on
every machine.

## `steps/` — installation step cards (generated)

`step-1.svg` … `step-8.svg`, generated by `tools/steps/generate.py` from `tools/steps/steps.json`. Don't
edit them by hand. They embed Lucide icons (ISC), see [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## `badges/` — platform badges (generated)

One badge per platform and route, generated by `tools/badges/generate.py` from the logos in `brands/` (and
`ui/home.svg` for Apple Home). Don't edit them by hand: change the list in the script and run it again.

```
python3 tools/badges/generate.py
```

The logos are embedded unmodified; large ones (Homey) as a scaled-down PNG, and the ESPHome logo with its
empty margin cropped away. Route colours follow the overview image: native API cyan, MQTT orange, Apple Home
red.

## `ui/` — own line icons

Simple 24 × 24 line icons, drawn for this project. They use `stroke="currentColor"` with a default colour of
`#334155` set on the root element, so they render in slate when used as an `<img>` on GitHub. To use a
different colour, change the `color="…"` attribute in the file, or inline the SVG and set `color` with CSS.

|---|---|
| `waves.svg` | Bluetooth (generic radio waves, **not** the Bluetooth logo) |
| `wifi.svg` | Wi-Fi (generic signal icon, **not** the Wi-Fi Alliance logo) |
| `home.svg` | Apple Home / HomeKit (generic house, **not** an Apple mark) |
| `mic.svg` | Siri (generic microphone) |
| `remote.svg` | Geberit remote control |
| `phone.svg` | Geberit Home app |
| `plug.svg` | USB powered (generic plug, **not** the USB logo) |

| `cloud-off.svg` | Fully local, no cloud |

## `user-interface/` — what the bridge looks like

Full-page captures of the bridge's entities, shown in the README under **Two routes → What it looks like**.
Each image is stitched together from consecutive screen captures of one page. Serial number, addresses,
firmware versions and keys are replaced by `xxx`.

| File | Shows |
|---|---|
| `native-api-integration.png` | Native API: the ESPHome integration with the bridge's devices (example: Home Assistant) |
| `native-api-aquaclean-bridge.png` | Native API: device **AquaClean Bridge** |
| `native-api-aquaclean-toilet.png` | Native API: device **AquaClean Toilet** |
| `native-api-active-session.png` | Native API: device **Active session** |
| `native-api-user-profile-1.png` | Native API: device **User profile 1** (profiles 2–6 look the same) |
| `native-api-physical-maintenance.png` | Native API: device **Physical maintenance** (only while it is unlocked) |
| `mqtt-device.png` | MQTT: all entities under one device (example: Home Assistant with MQTT discovery) |
| `mqtt-web-interface.png` | MQTT: the web interface on the ESP (`packages/web.yaml`), with user profile 1 only |

The Home Assistant pages show the ESPHome and MQTT logos as Home Assistant displays them; they are part of the
captured interface, not logos added by this project.
