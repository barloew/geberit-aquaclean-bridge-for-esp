Geberit AquaClean Bridge for ESP

Install from this page with Chrome or Edge and a USB cable. Pick a route: Native API for Home Assistant, Homey or ioBroker, or MQTT for an MQTT broker (openHAB, Node-RED, Domoticz, …). No Wi-Fi in the browser? The bridge opens the hotspot "AquaClean Setup" (captive portal) to enter it.

  1. Choose route Native API, your board and language, press Install and enter your Wi-Fi in the same window (or later on the "AquaClean Setup" hotspot).
  2. Open http://aquaclean-xxxxxx.local/setup (on the hotspot: http://192.168.4.1/setup), press Generate random key, copy it, then Save to bridge.
  3. Add the bridge in your controller — it is discovered automatically — and paste that key. Done.
  1. Choose route MQTT, your board and language, press Install and enter your Wi-Fi in the same window (or later on the "AquaClean Setup" hotspot).
  2. Open the bridge's web page (Visit device, or http://aquaclean-xxxxxx.local).
  3. Under AquaClean Bridge: enter the MQTT broker, port, user and password, choose the time zone and press Connect to MQTT broker. The bridge restarts and announces itself with MQTT discovery.

No USB? The ESP opens the hotspot "AquaClean Setup" when it knows no Wi-Fi.
